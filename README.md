# DataSort Pro — Сортировщик данных нового поколения

Привет! Это веб-приложение для работы с данными в форматах JSON, CSV и XML. Загружаешь файл, выбираешь что нужно — и готово.

## Что умеет

### Сортировка (11 алгоритмов)

**Базовые:**
- Стандартная — обычная сортировка по возрастанию/убыванию
- Естественная — правильно сортирует строки с числами (file1, file2, file10 вместо file1, file10, file2)
- Стабильная — сохраняет порядок одинаковых элементов

**По зависимостям между полями:**
- Прямая зависимость (A × B) — когда оба поля важны одинаково
- Обратная зависимость (-A × B) — ищем низкое A при высоком B
- Пропорциональная (A / B) — считаем эффективность, типа доход/затраты
- Корреляция Пирсона — анализирует связь между полями

**Продвинутые:**
- Взвешенная — задаёшь важность каждого поля
- По перцентилям — статистическое распределение
- По Z-оценке — находит аномалии в данных
- Кластерная — группирует похожие записи

### Конвертация форматов

Легко переводит между JSON, CSV и XML в любую сторону. Нужно для Excel? Конвертируй в CSV. Для API? В JSON.

### Удобства

- Drag & drop — просто перетащи файл
- История загрузок — всё сохраняется локально
- Умные рекомендации — приложение само подскажет оптимальные параметры
- Превью больших файлов — показывает первые 100 записей, чтобы не зависало

## Как это работает

### API

**POST /sort** — сортирует данные

Отправляешь:
```json
{
  "json_data": [...],
  "sort_field": "age",
  "reverse_sort": "yes",
  "algorithm": "standard",
  "second_field": "salary"
}
```

Получаешь:
```json
{
  "status": "success",
  "sorted_data": [...]
}
```

**POST /convert** — конвертирует формат

Отправляешь:
```json
{
  "json_data": [...],
  "target_format": "csv"
}
```

Получаешь:
```json
{
  "status": "success",
  "content": "name,age\nJohn,30\n..."
}
```

## История проекта

Начиналось всё с простой консольной утилиты на Python для сортировки JSON. Потом добавили больше алгоритмов, поддержку CSV и XML, а в итоге сделали полноценное веб-приложение с красивым интерфейсом.

Класс `Sorter` в `app.py` — это сердце проекта. Он умеет:
- Читать данные из разных форматов
- Применять 11 разных алгоритмов сортировки
- Обрабатывать ошибки (файл не найден, неверный формат, отсутствующие поля)
- Конвертировать между форматами

## Обработка ошибок

Всё покрыто try-except блоками:
- `FileNotFoundError` — файл не найден
- `ValueError` — неверный формат данных
- `KeyError` — поле для сортировки не существует
- `IOError` — проблемы с записью файла

Приложение не упадёт, а покажет понятное сообщение.

## Примеры использования

**Простая сортировка:**
Загружаешь файл с сотрудниками, сортируешь по зарплате по убыванию — видишь кто больше всех получает.

**Корреляция:**
Есть данные о продажах и рекламе? Алгоритм корреляции покажет, как они связаны.

**Кластеризация:**
Группирует похожие записи вместе — удобно для анализа данных.
