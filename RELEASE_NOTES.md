# DataSort Pro 2.0 Beta 🚀

Первый публичный релиз веб-версии приложения для сортировки и конвертации данных.

## Что нового

### 🎨 Современный дизайн 2026
- Темная тема с градиентами и анимациями
- Адаптивный интерфейс
- Плавные переходы и эффекты

### ⚡ Функциональность
- **11 алгоритмов сортировки**: от базовых до продвинутых (корреляция, кластеризация, Z-оценка)
- **Конвертация форматов**: JSON ↔ CSV ↔ XML
- **Drag & drop**: просто перетащи файл
- **Умные рекомендации**: приложение подскажет оптимальные параметры
- **История загрузок**: все сохраняется локально

### 🔧 Улучшения
- Автоматический запуск сортировки при применении рекомендаций
- Превью больших файлов (первые 100 записей)
- Копирование и скачивание результатов
- Обработка ошибок с понятными сообщениями

## Технологии
- Python 3.10+ (Flask, NumPy, SciPy)
- Vanilla JavaScript (без фреймворков)
- CSS3 с современными фичами

## Установка

```bash
cd myapp
pip install flask numpy scipy
python app.py
```

Открой http://127.0.0.1:5000

## Известные ограничения
- Это beta версия, возможны баги
- Рекомендуется для файлов до 10MB
- Работает только локально (не production-ready)
