# Инструкция по установке DataSort Pro

## Вариант 1: Установщик (рекомендуется для пользователей)

### Для пользователей

1. **Скачайте установщик**
   - Перейдите на страницу [Releases](https://github.com/Andrey-Zobnin/ProjectOfJson/releases)
   - Скачайте `DataSortPro_Setup_2.1.0.exe`

2. **Запустите установщик**
   - Двойной клик по скачанному файлу
   - Следуйте инструкциям мастера установки
   - Выберите папку для установки (по умолчанию: `C:\Program Files\DataSort Pro`)

3. **Готово!**
   - Ярлык появится на рабочем столе и в меню Пуск
   - Запустите DataSort Pro
   - Откроется браузер с приложением

### Удаление
- Панель управления → Программы и компоненты → DataSort Pro → Удалить

## Вариант 2: Portable EXE (без установки)

Если у вас уже есть `DataSortPro.exe`:

1. Просто запустите `START.bat` или `DataSortPro.exe`
2. Откроется браузер с адресом http://127.0.0.1:5000
3. Готово!

## Вариант 3: Сборка установщика самостоятельно (для разработчиков)

### Требования
- Windows 10/11
- Python 3.10 или выше
- Inno Setup 6 (для создания установщика)

### Шаги

1. **Установите зависимости**
   ```bash
   pip install -r requirements-build.txt
   ```

2. **Соберите EXE**
   ```bash
   python build_exe.py
   ```
   Или просто запустите `BUILD.bat`

3. **Установите Inno Setup**
   - Скачайте с https://jrsoftware.org/isdl.php
   - Установите (по умолчанию в `C:\Program Files (x86)\Inno Setup 6`)

4. **Создайте установщик**
   ```bash
   BUILD_INSTALLER.bat
   ```

5. **Готово!**
   - Установщик будет в папке `installer_output/`
   - Файл: `DataSortPro_Setup_2.1.0.exe`

```bash
pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5000

## Устранение проблем

### "Python не найден"
- Переустановите Python с галочкой "Add to PATH"
- Или укажите полный путь: `C:\Python310\python.exe app.py`

### "Ошибка импорта scipy"
```bash
pip install --upgrade scipy numpy
```

### "Порт 5000 занят"
- Закройте другие приложения на порту 5000
- Или измените порт в `app.py`: `app.run(port=5001)`

### EXE не запускается
- Проверьте антивирус (может блокировать)
- Запустите от имени администратора

## Системные требования

- **ОС**: Windows 10/11
- **RAM**: минимум 2 GB
- **Место**: 200 MB для EXE версии
- **Браузер**: Chrome, Firefox, Edge (любой современный)
