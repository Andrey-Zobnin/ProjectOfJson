# Инструкция по установке DataSort Pro

## Вариант 1: Готовый EXE (рекомендуется)

Если у вас уже есть `DataSortPro.exe`:

1. Просто запустите `START.bat` или `DataSortPro.exe`
2. Откроется браузер с адресом http://127.0.0.1:5000
3. Готово!

## Вариант 2: Сборка EXE самостоятельно

### Требования
- Windows 10/11
- Python 3.10 или выше

### Шаги

1. **Установите Python**
   - Скачайте с https://www.python.org/downloads/
   - При установке поставьте галочку "Add Python to PATH"

2. **Запустите сборку**
   ```
   BUILD.bat
   ```
   
3. **Дождитесь завершения**
   - Процесс займёт 3-5 минут
   - EXE файл появится в папке `dist/`

4. **Запустите приложение**
   ```
   START.bat
   ```

## Вариант 3: Запуск через Python (для разработчиков)

```bash
pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5000

## Устранение проблем

### "Python не найден"
- Переустановите Python с галочкой "Add to PATH"
- Или укажите полный путь: `C:\Python310\python.exe app.py`

### "Ошибка импорта scipy"
```bash
pip install --upgrade scipy numpy
```

### "Порт 5000 занят"
- Закройте другие приложения на порту 5000
- Или измените порт в `app.py`: `app.run(port=5001)`

### EXE не запускается
- Проверьте антивирус (может блокировать)
- Запустите от имени администратора

## Системные требования

- **ОС**: Windows 10/11
- **RAM**: минимум 2 GB
- **Место**: 200 MB для EXE версии
- **Браузер**: Chrome, Firefox, Edge (любой современный)
