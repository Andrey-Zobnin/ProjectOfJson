# DataSort Pro — Универсальный сортировщик данных

## Описание
Веб-приложение для сортировки, фильтрации и конвертации данных в форматах JSON, CSV и XML.

## Возможности

### Сортировка
- **Стандартная** — по возрастанию/убыванию
- **Естественная** — для строк с числами (file1, file2, file10)
- **Стабильная** — сохраняет порядок равных элементов
- **Прямая зависимость** — A × B
- **Обратная зависимость** — -A × B
- **Пропорциональная** — A / B
- **Корреляция Пирсона** — анализ взаимосвязи полей
- **Взвешенная** — w1×A + w2×B
- **По перцентилям** — статистическое распределение
- **По Z-оценке** — выявление аномалий
- **Кластерная** — группировка похожих записей

### Конвертация
- JSON → CSV, XML
- CSV → JSON, XML
- XML → JSON, CSV

### Дополнительно
- Drag & drop загрузка файлов
- История загрузок (localStorage)
- Рекомендации параметров сортировки
- Превью больших файлов (100 записей)
- Копирование и скачивание результатов

## API

### POST /sort
Сортировка данных.

**Параметры:**
- `json_data` — массив объектов
- `sort_field` — поле для сортировки
- `reverse_sort` — "yes"/"no"
- `algorithm` — тип алгоритма
- `second_field` — второе поле (для зависимостей)

**Ответ:**
```json
{"status": "success", "sorted_data": [...]}
```

### POST /convert
Конвертация формата.

**Параметры:**
- `json_data` — массив объектов
- `target_format` — "json", "csv", "xml"

**Ответ:**
```json
{"status": "success", "content": "..."}
```
