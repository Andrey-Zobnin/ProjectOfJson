# DataSort Pro — Веб-приложение

Современный сортировщик данных с веб-интерфейсом. Работает с JSON, CSV и XML.

## Что внутри

Это Flask-приложение с 11 алгоритмами сортировки и конвертацией форматов. Интерфейс сделан на чистом JavaScript без фреймворков — быстро грузится и работает.

## Возможности

### Сортировка

**Базовые алгоритмы:**
- Стандартная — классика
- Естественная — для строк с числами (file1, file2, file10)
- Стабильная — сохраняет порядок равных элементов

**Сортировка по зависимостям:**
- Прямая (A × B) — произведение двух полей
- Обратная (-A × B) — обратная зависимость
- Пропорциональная (A / B) — отношение полей
- Корреляция Пирсона — статистическая связь

**Продвинутые:**
- Взвешенная — w1×A + w2×B
- По перцентилям — статистическое распределение
- По Z-оценке — выявление аномалий
- Кластерная — группировка похожих записей

### Конвертация

Переводит между форматами:
- JSON → CSV, XML
- CSV → JSON, XML
- XML → JSON, CSV

### Фичи интерфейса

- Drag & drop загрузка
- История в localStorage
- Умные рекомендации параметров
- Превью больших файлов (первые 100 записей)
- Копирование и скачивание результатов

## API

### POST /sort

Сортирует данные.

**Параметры:**
```json
{
  "json_data": [...],
  "sort_field": "age",
  "reverse_sort": "yes",
  "algorithm": "standard",
  "second_field": "salary"
}
```

**Ответ:**
```json
{
  "status": "success",
  "sorted_data": [...]
}
```

### POST /convert

Конвертирует формат.

**Параметры:**
```json
{
  "json_data": [...],
  "target_format": "csv"
}
```

**Ответ:**
```json
{
  "status": "success",
  "content": "name,age\nJohn,30\n..."
}
```

## Как работает класс Sorter

Основной класс в `app.py`. Методы:

- `set_data()` — загружает данные
- `sort()` — стандартная сортировка
- `natural_sort()` — естественная сортировка
- `stable_sort()` — стабильная сортировка
- `sort_by_direct_dependency()` — прямая зависимость
- `sort_by_inverse_dependency()` — обратная зависимость
- `sort_by_proportional_dependency()` — пропорциональная
- `sort_by_correlation()` — корреляция Пирсона
- `sort_by_weighted()` — взвешенная
- `sort_by_percentile()` — по перцентилям
- `sort_by_zscore()` — по Z-оценке
- `sort_by_cluster()` — кластерная

Все методы обрабатывают ошибки и возвращают понятные сообщения.

## Примеры использования

**Сортировка сотрудников по зарплате:**
1. Загружаешь JSON с данными
2. Выбираешь поле "salary"
3. Порядок "по убыванию"
4. Жмёшь "Сортировать"

**Анализ корреляции:**
1. Загружаешь данные о продажах
2. Выбираешь алгоритм "Корреляция Пирсона"
3. Первое поле "реклама", второе "продажи"
4. Видишь как они связаны

**Конвертация для Excel:**
1. Загружаешь JSON
2. Переходишь в "Конвертация"
3. Выбираешь JSON → CSV
4. Скачиваешь и открываешь в Excel
