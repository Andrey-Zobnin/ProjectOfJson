# Инструкция по сборке релиза

## Что нужно

1. **Python 3.10+** с установленными зависимостями
2. **Inno Setup 6** - скачать с https://jrsoftware.org/isdl.php
3. **Pillow** (опционально, для создания иконки): `pip install pillow`

## Пошаговая инструкция

### Шаг 1: Подготовка

```bash
cd myapp
pip install -r requirements-build.txt
```

### Шаг 2: Создание иконки (опционально)

```bash
pip install pillow
python create_icon.py
```

Это создаст `icon.ico` и `icon.png`. Если хочешь свою иконку - замени `icon.ico`.

### Шаг 3: Сборка EXE

```bash
python build_exe.py
```

Или просто:
```bash
BUILD.bat
```

Подожди 3-5 минут. EXE появится в `dist/DataSortPro.exe`

### Шаг 4: Тестирование EXE

```bash
cd dist
DataSortPro.exe
```

Проверь что:
- Приложение запускается
- Открывается браузер на http://127.0.0.1:5000
- Загрузка файлов работает
- Сортировка работает
- Конвертация работает

### Шаг 5: Создание установщика

```bash
cd ..
BUILD_INSTALLER.bat
```

Установщик появится в `installer_output/DataSortPro_Setup_2.1.0.exe`

### Шаг 6: Тестирование установщика

1. Запусти `DataSortPro_Setup_2.1.0.exe`
2. Пройди процесс установки
3. Проверь что приложение работает
4. Удали через "Программы и компоненты"
5. Проверь что всё удалилось

### Шаг 7: Создание релиза на GitHub

1. Перейди на https://github.com/Andrey-Zobnin/ProjectOfJson/releases
2. Нажми "Create a new release"
3. Заполни:
   - **Tag**: `v2.1.0`
   - **Title**: `DataSort Pro 2.1.0 - Standalone Installer`
   - **Description**: Скопируй из RELEASE_NOTES.md
4. Загрузи файлы:
   - `DataSortPro_Setup_2.1.0.exe` (установщик)
   - `DataSortPro.exe` (portable версия из dist/)
5. Поставь галочку "Set as the latest release"
6. Нажми "Publish release"

## Структура релиза

```
Release v2.1.0
├── DataSortPro_Setup_2.1.0.exe  (Установщик, ~50-80 MB)
└── DataSortPro.exe               (Portable версия, ~50-80 MB)
```

## Что получит пользователь

### Вариант 1: Установщик (рекомендуется)
1. Скачивает `DataSortPro_Setup_2.1.0.exe`
2. Запускает установщик
3. Выбирает папку установки
4. Получает ярлык на рабочем столе
5. Запускает через ярлык

### Вариант 2: Portable
1. Скачивает `DataSortPro.exe`
2. Запускает напрямую
3. Работает без установки

## Размеры файлов

- **EXE**: ~50-80 MB (зависит от зависимостей)
- **Установщик**: ~50-80 MB (сжатый)

## Проблемы и решения

### "Антивирус блокирует"
- Это нормально для новых EXE файлов
- Добавь в исключения или подпиши сертификатом

### "Слишком большой размер"
- Это из-за NumPy и SciPy
- Можно оптимизировать, исключив ненужные модули

### "Долго запускается"
- Первый запуск может быть медленным
- Последующие запуски быстрее

## Автоматизация (будущее)

Можно настроить GitHub Actions для автоматической сборки:
- При создании тега автоматически собирается EXE
- Автоматически создаётся релиз
- Автоматически загружаются файлы
