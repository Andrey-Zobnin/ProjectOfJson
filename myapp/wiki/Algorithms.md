# Алгоритмы сортировки

## Обзор

DataSort Pro поддерживает 11 алгоритмов сортировки, разделённых на три категории:

1. **Базовые** — простые алгоритмы
2. **По зависимостям** — учитывают связь между полями
3. **Статистические** — используют математический анализ

---

## Базовые алгоритмы

### Стандартная сортировка

**Код:** `standard`

Классическая сортировка по одному полю.

```
Вход:  [{a: 3}, {a: 1}, {a: 2}]
Выход: [{a: 1}, {a: 2}, {a: 3}]
```

**Когда использовать:** Простая сортировка по числам или строкам.

---

### Естественная сортировка

**Код:** `natural`

Учитывает числа внутри строк.

```
Стандартная: file1, file10, file2
Естественная: file1, file2, file10
```

**Когда использовать:** Имена файлов, версии, идентификаторы с числами.

---

### Стабильная сортировка

**Код:** `stable`

Сохраняет исходный порядок равных элементов.

```
Вход:  [{a: 1, id: "X"}, {a: 1, id: "Y"}, {a: 1, id: "Z"}]
Выход: [{a: 1, id: "X"}, {a: 1, id: "Y"}, {a: 1, id: "Z"}]
       (порядок сохранён)
```

**Когда использовать:** Многоуровневая сортировка, сохранение порядка.

---

## Алгоритмы по зависимостям

### Прямая зависимость

**Код:** `direct`

**Формула:** `A × B`

Сортирует по произведению двух полей.

```
Данные: [{a: 2, b: 3}, {a: 4, b: 1}, {a: 1, b: 5}]
Расчёт: 2×3=6, 4×1=4, 1×5=5
Выход:  [{a: 4, b: 1}, {a: 1, b: 5}, {a: 2, b: 3}]
```

**Когда использовать:** Оценка совокупного влияния (цена × количество).

---

### Обратная зависимость

**Код:** `inverse`

**Формула:** `-A × B`

```
Данные: [{a: 2, b: 3}, {a: 4, b: 1}]
Расчёт: -2×3=-6, -4×1=-4
Выход:  [{a: 2, b: 3}, {a: 4, b: 1}]
```

**Когда использовать:** Поиск записей с низким A и высоким B.

---

### Пропорциональная зависимость

**Код:** `proportional`

**Формула:** `A / B`

```
Данные: [{доход: 100, затраты: 50}, {доход: 80, затраты: 20}]
Расчёт: 100/50=2, 80/20=4
Выход:  [{доход: 100, затраты: 50}, {доход: 80, затраты: 20}]
```

**Когда использовать:** Эффективность, ROI, конверсия.

---

### Взвешенная сортировка

**Код:** `weighted`

**Формула:** `0.6×A + 0.4×B`

Позволяет задать важность каждого поля.

**Когда использовать:** Рейтинги, скоринг с несколькими факторами.

---

## Статистические алгоритмы

### Корреляция Пирсона

**Код:** `correlation`

Учитывает статистическую связь между полями.

**Формула:** `A + r×B`, где r — коэффициент корреляции

```
r = 1   → сильная прямая связь
r = 0   → нет связи
r = -1  → сильная обратная связь
```

**Когда использовать:** Анализ взаимосвязи показателей.

---

### По перцентилям

**Код:** `percentile`

Сортирует по позиции в статистическом распределении.

```
Значения: [10, 20, 30, 40, 50]
Перцентили: 0%, 25%, 50%, 75%, 100%
```

**Когда использовать:** Ранжирование, сравнение с группой.

---

### По Z-оценке

**Код:** `zscore`

**Формула:** `z = (x - μ) / σ`

Показывает отклонение от среднего в стандартных отклонениях.

```
z > 2   → аномально высокое
z < -2  → аномально низкое
```

**Когда использовать:** Выявление выбросов, аномалий.

---

### Кластерная сортировка

**Код:** `cluster`

Группирует похожие записи вместе используя иерархическую кластеризацию (метод Уорда).

```
Вход:  разрозненные записи
Выход: записи сгруппированы по похожести
```

**Когда использовать:** Сегментация, группировка клиентов.
