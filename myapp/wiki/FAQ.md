# FAQ — Часто задаваемые вопросы

## Общие вопросы

### Какие форматы поддерживаются?

- **JSON** — массив объектов `[{...}, {...}]`
- **CSV** — таблица с заголовками в первой строке
- **XML** — структура с элементами `<item>`, `<record>`, `<row>` или `<entry>`

### Какой максимальный размер файла?

Технически ограничений нет, но для комфортной работы рекомендуется:
- До 10 000 записей — мгновенно
- До 100 000 записей — несколько секунд
- Более 100 000 — может потребоваться время

### Где хранятся мои данные?

Данные обрабатываются только в памяти и не сохраняются на сервере. История загрузок хранится в localStorage вашего браузера.

## Сортировка

### Какой алгоритм выбрать?

| Задача | Алгоритм |
|--------|----------|
| Простая сортировка | Стандартная |
| Файлы file1, file10 | Естественная |
| Цена × количество | Прямая зависимость |
| Доход / затраты | Пропорциональная |
| Найти аномалии | Z-оценка |
| Сгруппировать похожие | Кластерная |

### Что такое "второе поле"?

Некоторые алгоритмы (корреляция, зависимости) работают с двумя полями одновременно. Например, для расчёта эффективности нужны поля "доход" и "затраты".

### Почему результат пустой?

Возможные причины:
1. Применён фильтр, который исключил все записи
2. Выбрано несуществующее поле
3. Данные не являются массивом объектов

## Конвертация

### Как конвертировать JSON в CSV?

1. Загрузите JSON файл
2. Перейдите в раздел "Конвертация"
3. Нажмите на карточку "JSON → CSV"
4. Скачайте результат

### Почему некоторые карточки неактивны?

Карточки конвертации зависят от формата загруженного файла. Если загружен JSON, доступны только конвертации из JSON.

### Сохраняется ли структура данных?

Да, все поля и значения сохраняются. Однако:
- CSV не поддерживает вложенные объекты
- XML добавляет теги вокруг значений

## Проблемы

### Файл не загружается

**Проверьте:**
1. Формат файла (json, csv, xml)
2. Кодировку (должна быть UTF-8)
3. Синтаксис (валидный JSON/CSV/XML)

**Для JSON:**
```json
[
  {"field": "value"},
  {"field": "value"}
]
```

**Для CSV:**
```csv
field1,field2
value1,value2
```

### Ошибка "Нет данных для сортировки"

Убедитесь, что:
1. Файл загружен
2. Данные — это массив объектов
3. Выбрано существующее поле

### Приложение тормозит

**Решения:**
1. Используйте файлы меньшего размера
2. Обновите страницу (Ctrl+F5)
3. Очистите историю загрузок

### Не работает история

История хранится в localStorage. Проверьте:
1. Не включён приватный режим браузера
2. localStorage не заблокирован
3. Не превышен лимит хранилища

## Разработка

### Как добавить новый алгоритм?

1. Добавьте метод в класс `Sorter` (app.py)
2. Добавьте опцию в `<select id="algorithm">` (index.html)
3. Добавьте обработку в `algorithm_map` (app.py)

### Как изменить стили?

Все стили в `static/style.css`. Используются CSS-переменные:

```css
:root {
    --primary: #2563eb;
    --bg-dark: #f8fafc;
    /* ... */
}
```

### Как запустить тесты?

```bash
python -m pytest tests/
```

*(тесты в разработке)*
