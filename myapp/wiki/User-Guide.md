# Руководство пользователя

## Интерфейс

Приложение состоит из трёх основных разделов:

1. **Сортировка** — основной функционал
2. **Конвертация** — преобразование форматов
3. **История** — последние загруженные файлы

## Загрузка файла

### Способ 1: Drag & Drop

Перетащите файл в область загрузки.

### Способ 2: Выбор файла

Кликните на область загрузки и выберите файл.

### Поддерживаемые форматы

- **JSON** — массив объектов `[{...}, {...}]`
- **CSV** — таблица с заголовками
- **XML** — структура с элементами `<item>`, `<record>`, `<row>`

## Сортировка

### Базовые параметры

1. **Поле для сортировки** — выберите поле из данных
2. **Порядок** — по возрастанию или убыванию
3. **Алгоритм** — тип сортировки

### Алгоритмы

| Алгоритм | Когда использовать |
|----------|-------------------|
| Стандартная | Простая сортировка по одному полю |
| Естественная | Строки с числами (file1, file10) |
| Корреляция | Анализ связи между полями |
| Z-оценка | Поиск аномалий |
| Кластерная | Группировка похожих записей |

### Рекомендации

Нажмите кнопку **"Подобрать параметры"** — система проанализирует данные и предложит оптимальные настройки.

## Конвертация

1. Загрузите файл в исходном формате
2. Перейдите в раздел **Конвертация**
3. Выберите целевой формат
4. Скачайте результат

### Доступные конвертации

```
JSON → CSV, XML
CSV  → JSON, XML
XML  → JSON, CSV
```

## История

- Автоматически сохраняются последние 10 файлов
- Данные хранятся в браузере (localStorage)
- Можно удалить отдельные записи или очистить всю историю

## Результаты

### Превью

Для больших файлов (>100 записей) показывается превью первых 100 записей.

### Действия

- **Копировать** — скопировать в буфер обмена
- **Скачать** — сохранить файл на диск

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| Ctrl+V | Вставить данные (в разработке) |
| Ctrl+S | Скачать результат (в разработке) |
